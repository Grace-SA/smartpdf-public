# M9 添加页码产品与技术方案

M9 为一份 PDF 添加可见页码。原始页面、文字、图片和可保留结构保持原样；页码作为新的前景内容写入。全部在浏览器本地执行，不新增服务器转换或第三方字体请求。研究与设计基线日期为 2026-10-16，当前状态 Design；本地开发不授权生产发布。

## 编号口径

PDF 原始页位置、可见打印号、PDF PageLabels 是三件不同的事。M9 只新增可见打印号，不更改 PageLabels 或已有页码，也不改变页面顺序。

设选中页数为 C，起始号为 S。第 k 份选中页打印 S+k，末号 E=S+C−1。含总数的格式使用 E，即编号序列的终点；不是源 PDF 的物理页数。默认 S=1 时 E=C。格式选项旁简述“Total follows the last number”，摘要显示“PDF pages 2–6 · numbers 3–7”，预览和输出调用同一份编号计划。这样不会出现当前号大于分母的结果。

| 六页输入         | 起始号 | 可见结果                                  |
| ---------------- | ------ | ----------------------------------------- |
| 全部页           | 1      | 1–6；总数格式为 1 / 6 至 6 / 6            |
| 跳过封面         | 1      | 第一页无新增页码，后五页为 1 / 5 至 5 / 5 |
| 仅 PDF 第 2–6 页 | 3      | 3 / 7 至 7 / 7；摘要明确只编号五页        |
| 仅 PDF 第 4 页   | 12     | 12 或 12 / 12；其他页不变                 |

实测对照中，iLovePDF 的 Page n of p 模板保留源文件物理页数：上述第二至六页、首号 3 的配置，输出为 Page 3 of 6 至 Page 7 of 6。Smart PDF 采用统一编号终点口径，避免直接复制这个歧义。首版不增加多种总数算法切换、罗马数字、Bates 编号、双面镜像或自定义模板。

Start number 必须为 1–999999 的整数，且末号不超过 999999；无效或空白不默认为有效值。单页文档选择跳过封面时说明没有可编号页面并禁用生成。范围必须满足 1 ≤ From ≤ To ≤ 总页数。

## 页面状态和错误恢复

进入上传页保持静默准备；选定有效 PDF 后进入任务页。选择、准备、可编辑、生成中、失败、完成各自边界清晰。仅当前及邻近页面渲染 Canvas；滚动、前后页、直接输入页码及 Fit page/Fit width 沿用连续预览规则。切换设置只更新页码覆盖，不重建原页面 Canvas，避免闪烁。

进入生成时冻结设置，锁定其他修改，使用共享处理中弹窗与取消；Worker 中再次检查输入和全部计划，串行追加、验证输出页数/几何/结构，成功后由 App 提交新 File 并卸载编辑组件。取消、超时或失败不提交部分结果，保留原文件和设置；再次生成从原始文件开始。

输入维持一份 ≤30 MiB、≤200 页。输入和输出合计 ≤60 MiB，输出仍须满足共享单文件限制。0 页、空文件、损坏、加密、超量或现有不能保留的结构按原契约安全拒绝；标准声明及 C2PA 仍须用户明确同意后在任务内创建普通副本。不得扩大加密输入支持，不改写原文件，不静默扁平化表单或移除关联结构。

首页、Tools、More PDF tools、footer、直达地址、SEO 共用目录增加一个 Page Numbers 入口。上传区有 FAQ 和其他工具；编辑、完成阶段不加入 FAQ。统计只发送白名单事件、工具 ID 和分桶值，不包含编号文本、文件名或文档数据。本轮不修改生产统计后端，也不发布。

## 设计复核结论

采用成熟工具的短任务路径、位置网格、明确起始号和强下载层级；保留本站已验证的任务解耦和本地处理。去掉双页模式、复杂模板、云保存/分享和跨工具衔接，避免首版页面成为参数清单。总数规则、字体首载、输出几何及错误恢复已有明确方案和技术可行性证据，达到本地实现基线；最终质量以产品生成、全量回归和验收记录为准。

## 实现后再次对照（2026-10-19）

已对照前述竞品任务和实际 Smart PDF 桌面、390/320 窄屏及 844 横屏合成任务截图，逐项复查选择、设置、预览、执行、完成和新任务。六位置纸张图标、简单默认编号、折叠外观和唯一生成动作满足任务基线；封面/范围与自定义起始号采用同一计划，预览与下载不分别计算。完成阶段只保留输出摘要、下载及选择新文件，不恢复原编辑区，不加入云端操作或跨工具历史。

自查已修：页面重排时的跳页目标丢失；横屏高度较小时固定预览和底部动作遮住设置；全局表单样式给单选按钮和分组增加过多留白/边框。现在仅在有足够高度时保持手机预览固定，横屏可自然滚动设置，保持 44px 可点区域。参数调整保留底图 Canvas，只更新编号覆盖。字体首次失败可保留已选文件重试；正常就绪后断网生成不新增 HTTP 请求。累计回归另复现了既有签名页码输入被延迟聚焦抢走的问题，本轮补充输入焦点保护并连续验证。

该对照没有取得新的真机结果，不以桌面 WebKit 代替 iPhone。最终检查、已知限制及验收方式见 [M9 交付记录](../m9-report.md)。
