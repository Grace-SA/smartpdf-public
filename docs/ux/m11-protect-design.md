# M11 Protect PDF：产品、交互与技术基线

2026-10-29。源码评审与测试阶段；未作真实手机验收，未授权生产发布。

## 对照需求与竞品

需求第 15.1–15.3 节定义独立的密码保护任务：一份未加密 PDF → 输入并确认打开密码 → 生成 → 下载新文件。M12 解除已知密码和其他工具的加密准入不受影响。

沿用此前 M11 探索分支的研究，并于本次复核官方页面：

| 官方资料 | 可借鉴流程 | 本方取舍 |
| --- | --- | --- |
| [iLovePDF Protect](https://www.ilovepdf.com/protect-pdf) | 文件选择、两次输入密码、生成、下载；另有高级权限选项 | 保留短流程、明确不匹配提示，首版不增加权限面板 |
| [Adobe Protect](https://www.adobe.com/acrobat/online/password-protect-pdf.html) | 选择、密码及确认、设置、下载 | 统一主动作和完成边界，不加入账户或服务器上传 |
| [PDF24 Protect](https://tools.pdf24.org/en/protect-pdf) | 打开密码、可展开附加权限、下载；公开说明 AES-256 | 密码保护和阅读器权限不是同一保证，只提供打开密码 |

本次对竞品的复核限于官方页面与此前已记录的合成任务研究，不声称重新完成其全部在线任务，也不推断闭源引擎。

## 细粒度流程

1. **选择页**：共用导航、简短隐私提示、单文件原生选择器、上传区下面的支持范围、FAQ 和更多工具。异步准备保持静默，文件按钮不禁用、不跳动。
2. **检查**：文件读取和结构检查都可取消；拒绝原因就地显示。确定性拒绝不提供无意义的“重试”，仍可换文件或离开。资源故障、取消和超时允许重试。
3. **密码页**：文件名、页数、大小及“Choose another file”；两项明确标签，默认隐藏；一个 Show/Hide 控制两栏。至少 8 个 Unicode 字符、最多 127 UTF-8 字节，原样比较确认，不在应用中修剪、规范化或截断。错误解释靠近字段。只有文件通过、密码有效且完全相同才启用 Protect PDF；Enter 同样提交。
4. **处理**：清空可见输入及 React 密码状态，关闭显示密码；一次性 Worker 加密和核对，独立 PDF.js 检查密码。处理中只显示任务相关进度和取消按钮，避免重复提交。
5. **失败/取消**：保留原件选择，清空密码，销毁相关 Worker；有限错误文案不输出引擎原始诊断。重新输入才可再试。原件从不覆盖。
6. **离开**：沿用 Keep editing / Discard task and leave 二选一。换文件、新任务、导航离开均清空任务密码及输出；不引入跨任务历史。
7. **完成**：仅显示共用下载页，以 Download PDF 为唯一主操作，另有 Choose new files。密码框、编辑区和处理覆盖层均卸载。结果不自动传给其他任务，没有内嵌明文预览。

手机采用单列卡片、16px 输入、至少 48px 字段，文件名可换行；桌面保持同一聚焦流程。已自查 320/390px、横屏和桌面布局；模拟不等于 iPhone 真机验收。

## 技术选型与保真

- 复用锁定 `@neslinesli93/qpdf-wasm` 0.3.0，不新增依赖。实际二进制 SHA-256：`abd933f4ccace4f732999381b21aec8b7e3726f18a5b167fafd57f88dd440876`。官方原生支持不作为浏览器构建成功的替代证据。
- [qpdf 加密文档](https://qpdf.readthedocs.io/en/stable/encryption.html) 与[命令文档](https://qpdf.readthedocs.io/en/stable/cli.html)作为参数和密码角色依据。固定 Standard / V5 / R6 / 256-bit / AESV3，加密字符串、流和元数据，不提供弱加密降级，不承诺禁止已知密码的接收人复制/打印。
- 原始源字节交给 qpdf，保持流数据；pdf-lib 只读结构，不把源文档通过其另存后再加密。对可达 Catalog 和 Info 进行有界、与对象编号无关的逻辑图及内容摘要比较。加密产生的精确 Adobe 1.7 / ExtensionLevel 8 声明属于预期变化，其余差异阻止输出。
- 候选检查安全字典，再解密并与源逻辑图比较；独立 PDF.js 分别检查无密码、错误密码与正确密码。集成测试另外用 MuPDF 核对所有输出页的像素、文本、几何、导航、标签对应图、图层及表单。
- 支持普通链接、书签、PageLabels、图层、标签和受支持表单。已有加密、数字签名、标准符合性声明、C2PA、附件、主动内容和无法安全核对的结构首版明确拒绝，不静默删改。
- 输入/输出各 30 MiB、200 页、总任务 120 秒；单流解码约 8 MiB、摘要总工作量 128 MiB、私有 WASM heap 增长上限 192 MiB。后者不是整个浏览器总内存保证。
- 使用浏览器安全上下文的 Web Crypto，部署须 HTTPS（本机 localhost 也可）；非安全局域网 HTTP 给出明确提示，不悄悄降低密码学保证。

## 隔离与复用

密码不进入 URL、文件名、网络、控制台、埋点或持久存储。主线程可缓存公共 WASM 和独立读取器脚本；不缓存输入、密码或输出。与 M12 共用公共 WASM 准备工厂，仍有独立准入、请求和失败类型。

每次检查/加密创建一次性 Worker。qpdf 静态打包进内联 Worker，避免 blob Worker 中动态相对导入在生产 CSP 下失败；不放宽 CSP。虚拟文件固定命名、finally 清理，引擎诊断被截断在私有 Worker 内。成功、失败、取消、超时、消息异常和卸载均终止 Worker。独立读取器即使销毁确认不返回也立即终止私有端口。JavaScript 引用释放不能证明所有内存副本被物理擦除。

沿用现有仅含分桶计数、时长及稳定原因的聚合统计；不新增敏感字段。独立处理器与部署模板的工具白名单须与统一目录完全一致。
