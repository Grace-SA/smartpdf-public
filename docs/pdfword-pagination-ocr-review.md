# PDF to Word：分页与 OCR 完整性复核

状态：In Review，受限测试候选。139 份整份重跑、实际 Microsoft Word 16.115 验收及本地浏览器流程已完成；不等于通用保真上线通过。

## 范围与实现

本轮基线为 `1c1a133`，开发分支为 `development/pdf-to-word`。转换仍采用 Stirling Office Convert、原生结构重建和 OCR 的混合路由，并非所有输入都由 Stirling 转换。扫描、混合页面和公式保留现有 OCR 链路。

- 长表分页：保留原生字体及表头实际加粗状态，压缩空分节段落和图片行的多余占高，重复多行表头；不使用固定行高裁字。
- 页码孤页：混合页面的重复页边识别纳入已经由 OCR 标注的页眉、页脚证据，保持原阈值及几何约束。单页表格仅在原件存在唯一、与正文分离的数字页脚时迁入真正页脚；不删除页码，只有页码的原件不适用。
- 长文档包大小：无损合并相邻同格式纯文字片段，字段、书签、图片、公式及样式变化均为边界；保留既有 8MiB 单 XML 部件限制。
- OCR 截断：仅对文字区域进行保留全部像素的空白处分带重试；持续循环触发不完整重试，不能作为成功结束。任一分带仍截断则拒绝输出。
- 原生文字恢复：仅在未旋转、未去畸变、原本含原生文字的页面，且独立解析器与可见文字区域一致时恢复。图像覆盖、区域重叠、双向文字及可见控制字符等歧义不替换。
- 图中文字边界：短标签允许最多 2pt 的完整裁剪扩展，但不能侵入邻近文字或越出页面，原生覆盖校验不变。

成功率增加 0.72 个百分点，新增成功为上述 196 页文档。32 份失败与基线相同：23 份策略拒绝（10 交互内容、7 可见批注、4 加密、1 文件大小、1 嵌入文件或脚本），9 份转换或几何限制（3 安全转换失败、2 无可编辑文字、2 网格不完整、2 页面尺寸不支持）。不能将这些失败排除后宣称全部输入可用。

本轮 107 份实际 Word 共 845 页，包含新增文档的 263 页；不能直接与基线 648 页作配对比较。所有 845 页完成总览审查，关键分页、表头及 OCR 区域另行放大。正文、表格单元格及合并、公式和源页书签保留检查通过；61 份含表文档共 308 张表无超出所在栏宽的检测结果；36 份含图片文档的图片像素保留。页面尺寸与边距检查 107/107 通过。这些结构检查不证明表格语义、文字准确率或视觉保真。

“仅数字文字”自动检测在全部输出中仍标出新增文档的一张二维码续页；人工确认不是纯页码页，原始检测值与判读均保留。原本只有页码的负向样本仍保留，不计作缺陷。实际 Word 渲染按原输入及页序比较，89 页像素相同、756 页改变或新增；全部均纳入上述总览，不将像素变化数当作质量分数。

准确率使用原有固定参考：12 份表格的 2,762 格严格网格一致性，以及 3 份文字参考的 3,716 字符编辑距离。两者均不是 139 份的整体准确率。局部 OCR 人工参考只验证对应区域，不扩展为整页或整份准确率。

文字参考累计编辑距离仍为 115；仅去除空白，参考自身包含历史转录及标点差异。139 份缺少完整人工答案，整体转换准确率未知，不能用 96.91% 代替。新增第 41、64、131 页局部参考也不并入原有固定准确率分母。
