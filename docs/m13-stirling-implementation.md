# Stirling Word 转 PDF 实现与验收

2026-11-02：用户选择基于 Stirling 开发，替代此前 Gotenberg 的实施选择。2026-11-03 授权推进至可发布并新建专用主机。本文为当前实施基线；此前研究数据保留为历史。允许新主机初始化与验收，用户随后明确授权“继续执行，直至上线”；现在允许完成核心接入、必要的受审查合并和正式发布，仍须遵守对应提交 CI、干净 main 制品与回滚检查。

## 产品范围

入口为 `/word-to-pdf/`，首页、工具菜单与相关工具共用目录。单份标准 DOCX，输入上限 30 MiB、输出上限 30 MiB/200 页。选择文件不上传；用户主动选择 Upload and convert 后上传。沿用网站英文界面，明确云端处理、服务位置、临时保留、字体替代及分页变化。输出可预览、下载、删除；预览资源加载失败仍可下载。

普通中英文正文、表格、图片、目录、页眉页脚、脚注和分栏可进入转换；不保证 Word 原生排版一致。首次版本拒绝加密包、宏、嵌入对象/文件/字体、外部资源和主动数据域；为避免静默接受修订或披露隐藏内容，要求先在 Word 处理修订、批注与隐藏内容。普通 HTTP/HTTPS/mailto 超链接允许作为静态链接保留。

首页和隐私页已区分本地 PDF 工具与云端 Word 工具。文件名仅用于浏览器展示和下载命名；向服务器上传的文件名固定为 document.docx，服务日志不记录用户文件名或内容。首次版本无批量、账户、计费和第三方转换回退。

## 固定执行环境

当前接口采用 Stirling PDF 3.2.2 官方固定完整镜像，仅限内部验收。已独立验证不含受限附加模块的核心候选，详见本文末节；现有接口尚未替换为该候选。

`docker.stirlingpdf.com/stirlingtools/stirling-pdf@sha256:c6872dd056b0046a14c5de1e9970283e7f1e1ff685bb08090c6b37a231127d31`

实测 LibreOffice 26.2.6.3。字体使用该镜像的内置文件，不复制本机 Microsoft 字体，不接受用户安装字体，基线称 `stirling-3.2.2-builtin-v1`。已知常见西文字体替代为 Carlito/Liberation/Caladea，中文出现 Noto CJK HK/SC；不能承诺全部自动采用 SC。镜像变更必须重跑固定样本。此前 Gotenberg/Noto profile 不是本版运行环境。

已在固定镜像的只读、无网络、非 root 检查容器内生成 [279 个字体文件的哈希清单](../config/word-fonts.stirling-3.2.2.json)。清单仅包含镜像系统字体路径、大小和 SHA-256，不包含本机字体或任何文档。可用 `server/word/font_inventory.py` 复核。

Node 24 服务负责同源会话、流式上传、有界任务队列和 PDF 独立检查；Python 标准库负责 DOCX 预检与 Docker 任务执行。每个任务独立创建 Stirling 容器：2 CPU、2,560 MiB、禁用额外 swap、512 PID、无宿主目录挂载、无公开端口，内部 Docker 网络禁止外部出站。主机一次只运行一个转换，Node/Python 服务另限 768MiB；这是 2026-11-03 为专用 4GB 主机调整的候选预算，需要该主机实测，不把早期 4GiB 容器测试当成本预算已通过。保留官方镜像自身启动方式，不把它描述为已完成非 root/只读文件系统加固。

每任务启动完整 Stirling，冷启动通常需要约一分钟；这是本地验收版本的明显体验代价。界面显示真实阶段，不展示虚假的转换进度。后续若改为预热池或复用进程，必须重验任务隔离、取消和残留，不能默默改变当前保证。

## 生命周期与访问

`GET /api/word/session` 设置签名随机 HttpOnly/SameSite=Strict 会话 Cookie；HTTPS 环境加 Secure。任务 ID 不充当访问凭证。所有任务状态、结果、上传和删除检查会话归属，所有写接口检查精确 Origin。不配置跨站 CORS。

`POST /api/word/jobs` 建单，`PUT /jobs/:id/input` 原始 DOCX 流式上传，`GET /jobs/:id` 状态，`GET /jobs/:id/result` 已验证结果，`DELETE /jobs/:id` 取消或删除。最多 1 个执行任务、2 个等待/上传任务，每会话同时最多 1 个；最多保留 24 个任务记录/结果，避免无限积累。每会话/源 IP 有有界内存的请求速率限制。

包预检限制条目、路径、加密、压缩比、展开量、XML 大小/深度/节点并拒绝实体声明；不解包到任意路径。PDF 在独立、限内存的 Node worker 中解析，校验非加密、页数和页面尺寸，10 秒超时。HTTP 200 不直接算转换成功。

取消先撤销结果访问并标记取消文件，执行监视器移除本任务容器；迟到结果不能使任务恢复成功。删除接口提供 cleanupPending，前端等待清理确认。执行总时限 240 秒，使用镜像自带的 `/api/v1/info/status` 健康检查入口，启动阶段最多 150 秒，转换 HTTP 最多 90 秒，均受执行总时限约束；未上传任务 1 分钟过期，上传开始后独立计时，上传最多 120 秒。上传完成后的排队及执行期限为 16 分钟，覆盖三槽各自 300 秒工作进程保护并留余量，前端轮询同步；不将最长保护时间作为通常耗时。Node 对工作进程另设 300 秒保护，无法确认回收时停止接收新转换。取消或异常后删除输入/输出，成功后立即删除输入，结果在 59 分钟过期，30 秒清扫为一小时承诺留余量。已取消/失败记录短暂保留 1 分钟，随后释放容量。

服务启动先回收明确标记为本服务的孤立容器，再清除专用临时目录。仅支持同一主机单实例；不能并行启动两个本服务进程。清理失败时停止接受新转换，需要运维介入。专用目录必须排除备份和快照。

## 本地运行

Linux 需要 Node 24、Python 3、Docker，以及已安装的项目依赖。先拉取上述固定镜像，创建内部网络：`docker network create --internal smartpdf-word`。设置 `WORD_PUBLIC_ORIGIN` 为前端完整源，例如 `http://127.0.0.1:4240`；设置 `WORD_DATA_DIR` 为专用可清理目录，再运行 `npm run word:serve`。前端开发或预览使用 4240 端口，Vite 代理 `/api/word` 到本机 4268。

Windows 本地适配使用 WSL Ubuntu-24.04 内的 Python/Docker，Node 运行在 Windows；不依赖本机 Word。WSL 环境需要保持可用。生产目标为专用 Linux 主机，本次没有部署。

不设置 `WORD_DATA_DIR` 时，默认使用系统临时目录中的专用任务子目录；不将用户转换文件放入源码或 OneDrive 同步目录。实际部署仍应明确指定不进入备份的专用目录。

`WORD_PROCESSING_LABEL` 必须描述真实运行位置；开发机不得标为悉尼云机房。`WORD_API_TARGET` 可配置本地 Vite 代理目标；转换镜像及引擎端点不接受来自请求的覆盖。

提供 `infra/word/nginx.conf` 同源 HTTPS 代理片段和 systemd 服务模板。Docker 执行权限接近宿主管理权限，运行主机应为专用转换主机；模板不构成已完成的生产安全验收。上线前需在目标 Linux 主机验证权限、资源/磁盘压力、重启残留、反向代理与真实处理地区，且仍需明确生产授权。

本机 WSL 的同一页纯合成 DOCX 初测：冷启动端到端 38.987 秒，已有空闲容器时 11.266–13.347 秒；预热本身另需 17.176–31.317 秒。后者不能省略为总成本，首次使用、连续排队或修订路径仍可能更久。这些是本机固定镜像实测，不是线上 4GB Linux 的延迟承诺。未升级机器或复用含用户数据的 Office/Java 会话来换取速度。


后续实测进一步确认：同一容器的第一次转换 7.591 秒，后两次分别 0.231/0.276 秒，说明仅预热 HTTP 状态端点仍未完成 Office 转换路径初始化。就绪探针现使用代码内固定、无任何用户内容的合成 DOCX 完整转换一次；通过后才交接。每个容器仍只处理一份用户文档，之后销毁。预热期取消由独立监视器终止自有容器；已移除的空闲容器按健康 Docker 的不存在检查确认，不误报失败。缓存等待计入原任务执行预算，不通过扩大原有超时隐藏等待。取消、双重交接和关闭路径均测试；本机验收明确显示 Local conversion，避免用户将其误认为云端上传。

最终串行性能复测未同时运行重负载回归：普通一页合成 DOCX 冷启动端到端 37.038 秒；完成全部合成就绪探针后，普通文档两次为 2.563/2.583 秒，嵌入字体合成文档为 3.076 秒。对应空闲引擎准备另需 29.340/29.317/28.329 秒；不能将准备成本隐去，持续逐份转换仍受引擎重建吞吐限制。三次使用不同容器且用后移除。初次冷启动、连续任务、复杂排版和修订准备仍可能更慢；这些本机 WSL 结果不代替线上 4GB 主机验收。此次不改动已批准镜像或其 Office 沙箱启动脚本。
