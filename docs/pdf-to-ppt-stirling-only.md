# PDF → PPT：仅使用 Stirling

可编辑转换只使用自托管 Stirling PDF 3.2.2。已删除 Adobe PDF Services 适配器、凭据读取和页面云转换提示；默认 provider 为 `stirling`，仍必须配置 `SMARTPPT_STIRLING_URL`。旧配置中显式选择其他 provider 时，可编辑转换不可用，不会自动发送到其他服务。

扫描件继续使用本地 PaddleOCR，以及可选的 Unlimited OCR 2 / SoMark OXR 区域复核。请求中的旧语言参数暂时兼容，但不宣称它能指定 OCR 语言。API 不再提供云 OCR 能力。保真图片模式不需要 Stirling。

字体中的 Adobe 版权及 OFL 许可证必须保留；它们不是 Adobe 云转换依赖。此前质量报告中的 Adobe 描述为历史记录，不代表当前运行方案。

本功能仍是独立实验服务，尚未接入生产网站。合并代码不代表通过通用上线验收，也不部署服务。固定样本生成成功率、可编辑文字准确率、结构与位置通过率必须分别报告；图片回退不计为可编辑恢复成功。

本次验证包括 Stirling 请求协议、异常清理、取消与下载权限、旧 provider 拒绝、能力接口及 Chromium/WebKit 结果页面。移除 Adobe 专属测试会减少测试总数，不能将减少的计数误报为跳过测试。完整文档回归和真实 API 的完成状态另行记录；不使用旧版本结果证明新版本通过。

后续优先完成同一冻结版本的全量回归和 65 页报告 API 验收，再完成目录页排序候选、真实双栏扫描恢复及客户端字体验证。公开数据集标注也需检查漏字、错字和页脚覆盖后，才能用于准确率声明。
