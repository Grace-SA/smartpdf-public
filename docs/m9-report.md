## 实现范围

一份 PDF，最多 30 MiB、200 页。六个位置；全部页、跳过封面或连续页范围；自定义起始号；数字、当前号 / 末号、Page 当前号 of 末号三种格式；字号、物理边距和颜色。连续预览支持滚动、直接跳页、前后页和缩放。预览和生成共享编号计划，完成后只下载或选择新文件。

含总数的格式以最后打印号为终点。例如五个编号页从 3 开始，输出 3 / 7 至 7 / 7。已有页码和 PageLabels 不修改。普通副本确认沿用既有标准声明/C2PA 规则，未经确认不生成编辑结果。

技术和竞品依据：[方案及实现后对照](ux/m9-page-numbers-design.md)。复用现有本地引擎、覆盖几何、Worker、连续预览和完成页；新字体为既有 OFL 字体的 10,248 字节 ASCII 子集，无新增运行库。

## 已修问题

1. 尺寸重算与显式跳页竞争：保留明确跳页目标，用户自然滚动时释放，关闭浏览器与应用的重复滚动锚定。
2. 手机横屏设置被固定预览和动作栏遮住：高度不足时取消预览固定；缩紧单选/分组留白，保留触控尺寸。追加尺寸诊断发现跳页时输入框可见但整个预览框落在屏幕下方，因此显式跳页和尺寸重算同时保证外层预览框可见，并为底部动作栏预留空间。
3. 累计回归发现既有签名工具的延迟聚焦可能抢走页码输入：正在输入时不自动转移焦点，连续多轮验证。
4. 工具目录扩充后的旧测试预期：依据当前目录校验最后工具，等待实际目录挂载后核对全部链接，没有弱化工具完整性断言。
