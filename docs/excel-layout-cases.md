## 产品行为

新增可选的“Automatic layout for unconfigured tables”，默认仍是保留原打印设置。已有 pageSetup、打印区域/重复标题、手动分页或图形对象的工作表不套用推测的表格布局；显式纸张/方向选择仍生效。普通未配置表格按列宽、隐藏列及默认字体估算纸宽，在 A4 纵向/横向中选择；缩放不低于 85%，较小原字体进一步限制缩放。保持列宽、行高、合并结构、保存值和单元格样式，不裁掉格式区域或省略数据。

不能在可读字号下装进一页宽的表格允许横向分页。首行为普通文本表头、非合并标题且超过 20 行时重复首行；只有首列非空且每行标识唯一的宽表才重复首列。这样跨页阅读仍能对应原行。推断受限，最终 PDF 预览仍需核对；原稿本身的超长文本、过小字体、固定行高截字不会擅自重排。

用户于 2026-11-05 明确批准 Excel 输出上限提高到 500 页，Word 继续 200 页；30 MiB、192 MiB 校验堆、10 秒校验期限及对象/节点/深度/画布等预算保持不变。501 页明确拒绝，不偷偷删行或强缩字号。Excel 结果预览单独支持 500 页，并提供直接页码跳转；普通 PDF 工具和 Word 的 200 页默认范围不变。

同日用户明确批准 Excel 默认生成普通可搜索 PDF，不保留逐单元格的无障碍表格标签，不提供 PDF/UA 输出。仅在 Excel 专用镜像增加 PDF 导出配置，不改 Word 镜像。2 万行、12 万个单元格的公开压力样本输出 393 页；标签版有 268,418 个交叉引用对象，触发保留的解析预算，普通 PDF 只有 1,203 个对象。393 页的文字与几何全部一致，首/中/末页像素一致；实际服务校验约 0.7 秒。此项不是放宽解析保护，而是按已批准的输出类型避免标签对象膨胀。

## 研究与自查

[LibreOffice 打印分页说明](https://help.libreoffice.org/latest/en-GB/text/scalc/guide/print_exact.html)说明打印区域会按比例缩放并可跨页，因此按页宽压缩整个超宽表并不能保证可读性。[Smallpdf 的大表格说明](https://smallpdf.com/blog/how-to-convert-large-excel-table-to-pdf)同样建议检查打印区域与分页设置。本工具把可选布局、实际 PDF 预览、调整后重新生成放在同一流程；此轮没有上传私人样本给任何竞品，也不声称重新完成了第三方付费工具的实转对照。

首轮 12 类中宽表字号不达标，已提高缩放下限；随后公开页面目检发现四列备注仍横向拆页、宽表后半部分缺少行标识，修正估算和重复首列后增加了更严格的验收条件。原输入身份不变，失败记录保留在本机。UI 首次专项回归为 42 通过、320px 两项溢出失败；修正设置区最小宽度后 44 项通过；加入 500 页预览、直接跳末页及真实像素检查后双浏览器 46 项通过。完整累计测试与精确提交 CI 单独记录，不能以局部通过替代。

复现：`scripts/excel/layout_fixtures.py` 生成固定输入（`--large-only` 单独生成大文档），`scripts/excel/poc.py` 通过隔离的固定引擎实转，`scripts/excel/verify_layout.py` 独立检查所有 PDF 页并生成只包含合成数据的首尾总览，`scripts/excel/validate_outputs.mjs` 另行执行实际服务输出校验。生成文件及截图不提交；原 26 个固定案例和 25 个丰富内容案例不替换。
