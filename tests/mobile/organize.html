手动练习：10 页变 8 页

十页样本已自动载入，下方应用已展开页面整理。页面列表在整理按钮下方，需要向下滚动。 Original page 是原页码，Position 是新位置；手机上无需拖动。

  1. 在下方应用预览区找到 Go to page，输入 7 并点 Go，应显示 Page 7 of 10。 回到页面整理区，展开 Select a page range，输入 2-3，点 Select range， 应显示 2 selected。范围数字表示当前 Position，不是 Original page。
  2. 点击 None（清空选择），勾选原第 2、3 页。目标位置填 1，点击 Move（移到目标位置），再点 Rotate 90°（旋转）。 点 Enlarge selected pages，应看到旋转后的原第 2 页；点 Next selected 应看到原第 3 页。尝试 Zoom 200%、横竖屏和滚动，再点 Close enlarged page。
  3. 点击 None，滚动缩略图列表到底部，勾选原第 9、10 页，点击 Delete（删除选中页）。此时应剩 8 页。
  4. 先点 Combine PDFs 切换任务，应出现草稿确认框；点 Stay here（留在这里），确认刚才的修改还在。
  5. 点 Apply changes（应用修改），然后 Save PDF（保存）。在手机文件中打开：应为 8 页，顺序为 2、3、1、4、5、6、7、8，前两页旋转 90°。
  6. 再次点 Organize pages，横竖屏切换，确认缩略图和操作按钮可用。完成哪一项就勾选哪一项，恢复 Wi-Fi 后回传。

如果在普通应用中看到 Organize pages 灰置，需要先点 Choose a PDF 打开文件，等预览出现后才能整理。
