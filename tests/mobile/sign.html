手机验收 · M5 签名

本页只回传检查勾选、浏览器信息及版本编号，不读取 PDF、签名或姓名。请在独立产品页面操作。

准备

先保存这两个公开合成文件到 Files：

两页练习 PDF · 透明签名图片

打开 M5 产品页面

在产品页面选择 Sign PDF，打开练习 PDF，等页面显示并能点 Add signature。再关闭 Wi-Fi 和蜂窝网络；不要刷新页面。

依次检查

  1. 姓名签名：Add signature → Type → 输入“王小明 Alex” → 选择可用样式 → Use signature。点页面空白处放置，或点 Place at page center。
  2. 调整：点选签名，拖动或点 Move 后点新位置；用 Size 等比缩放。Delete 后点 Undo，签名应恢复；用 Pages 切换第二页，Add another 放置同一个签名。
  3. 手绘与图片：New signature → Draw，画一笔，检查 Clear / Undo stroke，再使用；另用 Image 选择练习 PNG，放到页面。横竖屏切换，检查页面和按钮均可操作。
  4. 完成：Create signed PDF → Download PDF。保存到 Files 后打开，核对两页、原内容、三种签名的位置及大小。完成页不应出现跨任务编辑或历史。
  5. 切换任务：恢复网络后，通过导航切到 Split PDF / Merge PDF，文件选择器应能正常打开，且没有上一任务的文件。
