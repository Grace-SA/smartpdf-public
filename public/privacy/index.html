Privacy

Your selected PDFs and images are processed on your device. Smart PDF does not send file contents or file names to its analytics service.

Aggregate website analytics

We use Cloudflare Web Analytics to understand visits and website performance. We may also record limited product events such as opening a tool, starting or completing a task, a broad failure category, and starting a download.

Product events contain only the tool name and coarse ranges for file count, size, page count and processing time. They do not contain document contents, file names, free-form error text, full URLs, account identifiers or persistent user identifiers.

Word to PDF cloud conversion

Word to PDF is a separate cloud tool. Your DOCX is uploaded to our self-hosted Stirling PDF conversion server only when you choose Upload and convert. The conversion page identifies the processing location. Documents are not sent to Adobe or another conversion provider.

We use a temporary anonymous session cookie to restrict access to your conversion. Inputs are removed after processing; results expire within one hour. Delete temporary files revokes access and requests cleanup immediately. Closing a page requests cleanup when possible; expiry also applies if the browser cannot send that request. Conversion storage must be excluded from backups. Document names and contents are not recorded in application logs.

Passwords for local tools

Unlock PDF passwords are used only for the current task on your device. They are not sent to our servers or analytics, added to URLs or saved in browser storage. Completing, cancelling or leaving a task releases password references and its private processing worker.

Local storage for other tools

Other PDF and image tools do not store a server copy of your task. Starting a new task or closing the page releases the in-browser working data, subject to normal browser memory management and downloads you choose to save.
