Smart PDF Word to PDF uses a self-hosted Stirling PDF service, communicating over HTTP.
No Stirling frontend or Java source is copied into the Smart PDF frontend.

Pinned upstream distribution: Stirling PDF 3.2.2
https://github.com/Stirling-Tools/Stirling-PDF
https://github.com/Stirling-Tools/Stirling-PDF/blob/v3.2.2/LICENSE

The upstream root license is MIT with explicitly listed directory exceptions.
The official container contains additional software and fonts under their own licenses.
Operators must preserve and review the licenses supplied with their pinned image.
Smart PDF does not represent the entire upstream distribution as unconditionally MIT.

LibreOffice: https://www.libreoffice.org/about-us/licenses/
This integration does not include or install Microsoft fonts from a user's device.

The Excel-only overlay restores LibreOffice 26.2.6.3 Colibre document icon resources
from the upstream Ubuntu PPA package. Its download SHA-256 is locked in
server/excel/Dockerfile; the package copyright notice is retained inside the image
at /usr/share/doc/excel-colibre/copyright. The chart-capable Excel overlay is pinned
separately in config/excel-core.stirling-3.2.2.json and does not replace Word's pin.
The 60 OOXML table-style definitions derive from Apache POI, Apache License 2.0;
source attribution and license are in server/excel/NOTICE and LICENSE-APACHE-2.0.txt.
Excel's CJK fontconfig aliases reuse the already installed, licensed Noto CJK fonts.
They do not add, copy or redistribute Microsoft fonts and do not imply identical
metrics to the original Office fonts. The aliases are scoped to the Excel image.

The public Word service uses the separately released server-only core JAR, not the full upstream application image. Its approved content ID and all build-input hashes are recorded in config/word-core.stirling-3.2.2.json. The upstream app/proprietary license restricts unlicensed client-facing use; disabling login in the full image is not a substitute for using the core build. Preserve the root MIT notice and every bundled third-party/font notice. Rebuilding never automatically approves a new runtime image.
